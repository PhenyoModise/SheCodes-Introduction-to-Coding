# Weather App

**Course section:** Week 2

## Overview

A weather page that prompts for a city and temperature and updates the heading and weather emoji. Temperatures of 20°C or higher show sunshine, 10°C or lower show a cold emoji, and values between show a partly cloudy emoji.

## Concepts demonstrated

JavaScript prompts, conditional statements, DOM selection, event listeners.

## Run locally

Open `index.html` in a web browser.
