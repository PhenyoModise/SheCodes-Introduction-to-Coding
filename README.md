# SheCodes Introduction to Coding

![SheCodes Introduction to Coding](assets/sheCodes-IntroToCoding.png)

A collection of lessons and web projects from **SheCodes Introduction to Coding**, taught by **Matt Delac**. The repository follows the progression from HTML and CSS foundations to JavaScript interactions and a final hobby landing page.

## Course overview

| Section | Topics | Materials |
| --- | --- | --- |
| Week 1: HTML and CSS | HTML elements and attributes, links, images, CSS selectors, classes, spacing, hover states and containers | [Week 1 notes](week-01-html-css/) |
| Week 2: JavaScript | Variables, strings, prompts, alerts, conditions, functions, DOM selectors and events | [Week 2 notes](week-02-javascript/) |
| Final project | Applying HTML, CSS and JavaScript to a hobby landing page | [Coffee hobby landing page](projects/coffee-hobby-landing-page/) |

## Projects

| Project | Description | Open |
| --- | --- | --- |
| Weather app | Change the city, temperature and displayed weather emoji | [View project](projects/weather-app/) |
| Application page | Prompt for a name and age, and show an age-based eligibility message | [View project](projects/application-page/) |
| SheCodes landing page | SheCodes-inspired layout with links to official SheCodes pages | [View project](projects/shecodes-landing-page/) |
| Coffee hobby landing page | Coffee-themed landing page with an interactive brew quiz | [View project](projects/coffee-hobby-landing-page/) |

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser DOM and event handling

## Running the projects

Open a project's `index.html` file in a modern web browser. Each project is self-contained and does not require a build process.
